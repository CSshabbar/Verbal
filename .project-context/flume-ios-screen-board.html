What the walk found

  1. Insights WPM number clipped. heroNum set a 52 px font on a <Text> whose default variant carries lineHeight: 25; iOS clips to the line box. Now lineHeight: 56.
  2. History detail showed no transcript. Card passed a function-valued style to a plain View whenever onPress was absent, so the card lost its surface and flex: 1 and collapsed. Regression from the app-wide press-feedback pass three weeks ago; affected every non-pressable Card.
  3. Confirm dialogs dead on modal screens. confirm() rendered a JS Modal that never appears over native-stack modals (Settings, Devices, Snippets, Team). Settings → “Replay onboarding” did nothing; Team’s Remove/Leave had the same fault. confirm() now routes to native Alert on iOS, fixing all callers.
