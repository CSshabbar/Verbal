# Linux runtime + build dependencies.
#
# requirements.txt is NOT sufficient for Linux: it omits scipy (imported at module scope by
# app/recorder.py) and comments out faster-whisper, so a clean build fails on the first
# import of the recording path.
#
# SYSTEM packages are required too — install these BEFORE pip, and create the venv with
# --system-site-packages so PyGObject is visible to it:
#
#   sudo apt install -y \
#       python3-gi gir1.2-ayatanaappindicator3-0.1 gir1.2-webkit2-4.1 \
#       python3-tk libportaudio2 xdotool xclip wl-clipboard
#   python3 -m venv --system-site-packages .venv
#
# Why each system package: python3-gi + appindicator GIR = a tray icon that actually docks
# on GNOME/Wayland (without it pystray falls back to _xorg, which has NO menu); webkit2 GIR
# = the pywebview GTK backend for the dashboard; python3-tk = the status overlay;
# libportaudio2 = sounddevice; xdotool/xclip = paste + clipboard; wl-clipboard = native
# Wayland clipboard (pyperclip prefers it automatically once wl-copy AND wl-paste exist).
